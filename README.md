# quote-displayer-app

A minimalist React app displaying a random "Quote of the Day" with a refresh button.

## How to Run

1.  **Save the files:**
    -   Create a folder named `quote-displayer-app`.
    -   Inside this folder, save the `index.html` file.
    -   Create a subfolder named `src` inside `quote-displayer-app`.
    -   Save the `app.js` file inside the `src` folder.
    Your directory structure should look like this:
    ```
    quote-displayer-app/
    ├── index.html
    └── src/
        └── app.js
    ```
2.  **Open `index.html`:** Simply open the `index.html` file in your web browser.

The app uses CDN links for React, ReactDOM, and Babel to run directly in the browser without a build step. Click "New Quote" to fetch another random quote.
